# Vehicle CAN Simulator

## Overview
The Vehicle CAN Simulator is a project designed to simulate the Controller Area Network (CAN) communication for vehicles. It allows developers and engineers to test and validate their CAN protocols and messages in a controlled environment.

## Setup Instructions
To set up the project locally, follow these steps:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/yourusername/vehicle_can_simulator.git
   cd vehicle_can_simulator
   ```

2. **Install Dependencies**
   Make sure you have [Android Studio](https://developer.android.com/studio) installed along with the necessary SDKs and tools.

3. **Open the Project**
   Open the project in Android Studio.

4. **Build the Project**
   You can build the project using Gradle. Run the following command in the terminal:
   ```bash
   ./gradlew build
   ```

## Usage
After building the project, you can run the application on an Android device or emulator. The application will allow you to simulate and interact with CAN messages.
